# FAQ-бот репетиции

Терминальный чат-бот на Python, который отвечает на 5 заранее известных
вопросов про музыкальную репетицию: время, команда, трек, сдача номера,
призы. Работает офлайн, без внешних API, RAG и векторных баз — только
сопоставление по ключевым словам.

Проект задуман как лёгкий кейс для репетиции командной работы:
от клонирования репозитория до рабочего бота — 30–60 минут.

---


---

## Что делает бот

1. Читает файл `faq.txt` с 5 парами «вопрос — ответ».
2. Ждёт, пока пользователь введёт вопрос в терминале.
3. Ищет среди 5 записей ту, что ближе всего по ключевым словам.
4. Печатает найденный ответ.
5. Если ничего похожего нет — отвечает «не знаю».
 Только Python стандартная библиотека.
